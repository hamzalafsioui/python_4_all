# 14_data_science_basics

## What Will I Learn?
This module covers: NumPy, Pandas, data cleaning, and data visualization (matplotlib, seaborn).

## Why Is It Important?
These libraries are the foundational tools for all data manipulation, analysis, and machine learning pipelines in Python.

## Prerequisites
13_networking_web_basics

## Estimated Time
8-12 hours

## Learning Objectives
By the end of this module, you will be able to:
- Manipulate arrays efficiently using NumPy.
- Work with tabular data using Pandas DataFrames and Series.
- Clean and prepare real-world datasets for analysis.
- Create publication-quality data visualizations using Matplotlib and Seaborn.

## Files in This Module
- `README.md` — This file
- `requirements.txt` — Dependencies for this module
- `numpy/` — NumPy basics, arrays, operations
- `pandas/` — Pandas Series, DataFrames, data manipulation
- `data_cleaning/` — Handling missing data, duplicates, outliers, formatting
- `data_visualization/` — Matplotlib and Seaborn plotting
